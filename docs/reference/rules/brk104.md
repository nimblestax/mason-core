## What it checks

This Brickie doesn't support that `version`.

## Why

The file is written against a schema this Brickie doesn't have, usually because a newer Brickie wrote it. Checking it against another version's schema would give wrong answers.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`domains/sales/sources/orders.yaml`:

```yaml
kind: source
version: 2
path: /Volumes/{env}_sales/bronze/landing/orders
format: json
```

## Fix

Use a version this Brickie supports, which the diagnostic lists. If the file needs a newer Brickie, upgrade Brickie in the project so everyone runs the same one.
