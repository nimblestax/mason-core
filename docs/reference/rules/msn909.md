## What it checks

`mason init` was run in a folder that already holds `mason.platform.yaml`.

## Why

`mason init` writes a new project. Writing it over an existing one would replace the Platform Contract and every starter file you've edited, so it writes nothing instead. Other files in the folder are fine, so a new Git repo with a README works.

## Example

In a project, this fails:

```console
$ mason init
```

## Fix

Run `mason init` in another folder, or give it one, as `mason init <folder>`.
