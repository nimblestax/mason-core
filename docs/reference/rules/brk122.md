## What it checks

`brickie.platform.yaml` has no `host` on the Development Environment. In a version 1 file, which knows Environments by name, it has no `host` on `dev`.

## Why

The Development Environment is the one every project starts from, and its `host` is the workspace Brickie connects to. Every other Environment uses its `host` unless it sets its own, so without it no Environment has a workspace.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`brickie.platform.yaml`:

```yaml
kind: platform
version: 2
name: shop
environments:
  dev:
    role: development
naming:
  style: domain-catalogs
  layers:
    models: [gold]
domains:
  - sales
```

## Fix

Add `host` under the Development Environment, such as `environments.dev`, set to its workspace URL.
