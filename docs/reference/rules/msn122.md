## What it checks

`mason.platform.yaml` has no `host` on the dev Environment.

## Why

dev is the Environment every project starts from, and its `host` is the workspace Mason connects to. test and prod use dev's `host` unless they set their own, so without it no Environment has a workspace.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`mason.platform.yaml`:

```yaml
kind: platform
version: 1
name: shop
environments:
  dev: {}
naming:
  catalog: "{env}_{domain}"
  schema: "{layer}"
  layers:
    sources: [bronze, silver]
    models: [gold]
domains:
  - sales
```

## Fix

Add `host` under `environments.dev`, set to dev's workspace URL.
