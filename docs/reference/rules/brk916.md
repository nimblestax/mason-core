## What it checks

`brickie init --example` names an example Brickie doesn't ship.

## Why

`brickie init --example` writes one of the example projects that ship inside Brickie, so the example always matches the Brickie you have installed. The diagnostic lists the examples there are. It exits 2, because the command line needs a change.

## Example

In a project, this fails:

```console
$ brickie init --example teapot
```

## Fix

Name an example the diagnostic lists, such as `brickie init --example kettle`.
