## What it checks

A model Layer in `naming.layers.models` is called `bronze` or `silver`, in any case.

## Why

Every Source fills bronze and silver, and only Gold Models fill model Layers. A model Layer with a source Layer's name would put Gold Models in the same schema as Sources, and a Logical Name such as `sales.silver.orders` could name either.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`mason.platform.yaml`:

```yaml
kind: platform
version: 2
name: shop
environments:
  dev:
    host: https://your-workspace.cloud.databricks.com
naming:
  style: domain-catalogs
  layers:
    models: [gold, silver]
domains:
  - sales
```

## Fix

Rename the model Layer, such as to `gold` or `marts`, and rename its folder under `models/` to match.
