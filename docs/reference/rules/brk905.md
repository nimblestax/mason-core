## What it checks

Brickie stopped on something it didn't expect, with a traceback on stderr.

## Why

Something went wrong that isn't a problem in the project or on the command line. Brickie still reports it as a diagnostic, as an envelope with `--json`, and exits 2, so scripts keep working.

## Example

The disk is full. In a project, this fails:

```console
$ brickie compile
```

## Fix

Read the traceback on stderr. If your machine isn't the cause, report a bug at https://github.com/nimblestax/brickie-core/issues with the traceback.
