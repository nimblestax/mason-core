## What it checks

`brickie skills update` found a Brickie Skill edited since Brickie wrote it.

## Why

Each Brickie Skill records a digest of the text Brickie wrote. A skill whose text no longer matches was edited, and updating it would lose the edit, so `brickie skills update` writes nothing and shows the difference instead. Exits 2.

## Example

A step was added to `.claude/skills/brickie-add-model/SKILL.md`. In a project, this fails:

```console
$ brickie skills update
```

## Fix

Move your edit into a skill of your own, outside the `brickie-*` folders, and run `brickie skills update` again. To replace the edit, run `brickie skills update --force`.
