## What it checks

A version 1 `brickie.platform.yaml` lists source Layers other than `[bronze, silver]`.

## Why

Every Source makes a bronze table and a silver table, and Brickie decides what each one does: Expectations, quarantine and exported silver. Another name would only relabel them, so the source Layers are always bronze and silver, and version 2 has no field for them.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`brickie.platform.yaml`:

```yaml
kind: platform
version: 1
name: shop
environments:
  dev:
    host: https://your-workspace.cloud.databricks.com
naming:
  catalog: "{env}_{domain}"
  schema: "{layer}"
  layers:
    sources: [bronze, curated]
    models: [gold]
domains:
  - sales
```

## Fix

Remove `naming.layers.sources`, and set `version: 2` with `naming.style`. To add a Layer, add it to `naming.layers.models`.
