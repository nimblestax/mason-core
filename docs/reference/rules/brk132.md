## What it checks

An Environment's name in `brickie.platform.yaml` isn't an identifier: letters, digits and underscores, starting with a letter or underscore.

## Why

An Environment's name goes into each of its catalogs, so `prd` gives `prd_sales.silver.orders`. Brickie writes catalog names into SQL unquoted, so the name must be an identifier.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`brickie.platform.yaml`:

```yaml
kind: platform
version: 2
name: shop
environments:
  dev:
    host: https://your-workspace.cloud.databricks.com
    role: development
  prd-1: {}
naming:
  style: domain-catalogs
  layers:
    models: [gold]
domains:
  - sales
```

## Fix

Rename the Environment to letters, digits and underscores, such as `prd` or `test_2`.
