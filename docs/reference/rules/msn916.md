## What it checks

`mason init --example` names an example Mason doesn't ship.

## Why

`mason init --example` writes one of the example projects that ship inside Mason, so the example always matches the Mason you have installed. The diagnostic lists the examples there are. It exits 2, because the command line needs a change.

## Example

In a project, this fails:

```console
$ mason init --example teapot
```

## Fix

Name an example the diagnostic lists, such as `mason init --example kettle`.
