## What it checks

Brickie couldn't download its Databricks CLI.

## Why

Brickie downloads its pinned Databricks CLI from Databricks' GitHub releases the first time it needs it, then reuses it. This machine couldn't reach GitHub, or GitHub refused the download. Brickie honours `HTTPS_PROXY` and `NO_PROXY`.

## Example

This machine has no internet access and no proxy is set. In a project, this fails:

```console
$ brickie deploy --env dev
```

## Fix

Check the machine can reach github.com, setting `HTTPS_PROXY` if it needs a proxy. On a machine that can't reach it at all, install the Databricks CLI yourself and point `BRICKIE_DATABRICKS_CLI` at it.
