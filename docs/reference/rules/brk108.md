## What it checks

A SQL file has no config file beside it.

## Why

A Gold Model is a SQL file and a config file beside it, which says it's a model and names the SQL. Brickie reports a SQL file on its own rather than skipping it, so a model can't silently drop out of a deploy.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`domains/sales/models/gold/fct_returns.sql`:

```sql
SELECT order_id
FROM sales.silver.orders
```

## Fix

Add a config file with the same name beside it, with `kind: model`, `version: 1` and `sql` naming the SQL file.
