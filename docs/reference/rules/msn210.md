## What it checks

A Gold Model reads bronze.

## Why

Tables are built in a fixed order: bronze, then silver, then gold. Bronze keeps every row as it landed, untyped and with duplicates, and only its own silver reads it. A Gold Model reads silver, where rows are conformed and checked, so a change to bronze reaches gold only through silver.

## Example

Write this file into the project `mason init` creates, and `mason validate` fails:

`domains/sales/models/fct_orders.sql`:

```sql
SELECT order_id, amount
FROM sales.bronze.orders
```

## Fix

Read the silver table of the same name, which the diagnostic gives.

## Principle

This Rule enforces [Data flows one way](https://nimblestax.com/way/data-flows-one-way), from the Nimblestax Way.
