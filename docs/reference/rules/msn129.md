## What it checks

A Mason Skill in `.agents/skills/` or `.claude/skills/` was written by another version of Mason than the one installed.

## Why

Mason Skills guide a coding agent through Mason's commands, and each one records the Mason version that wrote it. A skill from another version can name commands, options or steps the installed Mason doesn't have, so an agent follows stale steps. This is a warning: `mason validate` still passes.

## Example

Write this file into the project `mason init` creates, and `mason validate` warns:

`.agents/skills/mason-add-source/SKILL.md`:

```markdown
---
name: mason-add-source
description: Add a Source to a Mason project.
metadata:
  mason-version: "0.1.0"
---

# Add a Source
```

## Fix

Run `mason skills update`, which refreshes both copies of each skill, and commit them.
