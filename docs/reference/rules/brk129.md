## What it checks

A Brickie Skill in `.agents/skills/` or `.claude/skills/` was written by another version of Brickie than the one installed.

## Why

Brickie Skills guide a coding agent through Brickie's commands, and each one records the Brickie version that wrote it. A skill from another version can name commands, options or steps the installed Brickie doesn't have, so an agent follows stale steps. This is a warning: `brickie validate` still passes.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` warns:

`.agents/skills/brickie-add-source/SKILL.md`:

```markdown
---
name: brickie-add-source
description: Add a Source to a Brickie project.
metadata:
  brickie-version: "0.0.9"
---

# Add a Source
```

## Fix

Run `brickie skills update`, which refreshes both copies of each skill, and commit them.
