## What it checks

`mason skills update` found a Mason Skill edited since Mason wrote it.

## Why

Each Mason Skill records a digest of the text Mason wrote. A skill whose text no longer matches was edited, and updating it would lose the edit, so `mason skills update` writes nothing and shows the difference instead. Exits 2.

## Example

A step was added to `.claude/skills/mason-add-model/SKILL.md`. In a project, this fails:

```console
$ mason skills update
```

## Fix

Move your edit into a skill of your own, outside the `mason-*` folders, and run `mason skills update` again. To replace the edit, run `mason skills update --force`.
