## What it checks

A folder under `domains/` isn't listed in `domains` in `brickie.platform.yaml`, in the same case, so nothing in it is validated or deployed.

## Why

`domains` in `brickie.platform.yaml` lists the project's Domains, and Brickie reads only those folders. A folder it doesn't list would be silently left out of every check and every deploy. A folder that differs only in case is found on some file systems and not others, so it's reported too.

## Example

Write this file into the project `brickie init` creates, and `brickie validate` fails:

`domains/hr/sources/employees.yaml`:

```yaml
kind: source
version: 1
path: /Volumes/{env}_hr/bronze/landing/employees
format: json
```

## Fix

Add the folder to `domains` in `brickie.platform.yaml`, matching its case, or remove the folder.
