## What it checks

Databricks publishes no CLI for this operating system and architecture.

## Why

Mason downloads the Databricks CLI archive for this machine. Databricks publishes one for Linux, macOS and Windows, each on x86-64 and ARM, and nothing else.

## Example

Mason runs on 32-bit Linux. In a project, this fails:

```console
$ mason deploy --env dev
```

## Fix

Build or install a Databricks CLI for this machine and point `MASON_DATABRICKS_CLI` at it.
